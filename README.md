# NekoMusic（简洁音乐播放器，适配小米 Note 17 Pro / HyperOS）

一个面向 Android 手机的极简音乐播放器（应用名 **NekoMusic**，渐变紫粉主题 UI）：**自动扫描并导入设备本地音乐**、**导入网易云 / 酷狗 / QQ音乐 / 汽水音乐歌单**，
支持**顺序播放 / 列表循环 / 单曲循环 / 随机播放**四种播放顺序和**倍速播放**。界面是单个网页文件，外面包了一层极小的原生壳
（WebView），不依赖任何第三方库。

## 功能
- **自动寻找并导入音源**：启动时自动申请权限并扫描手机内全部本地音乐（MediaStore），去重后加入播放队列；也可随时点“扫描设备音乐”重新导入。
- **多平台歌单导入**：切换渠道（网易云 / 酷狗 / QQ音乐 / 汽水音乐）后粘贴歌单链接或 ID 即可导入公开歌单：
  - 网易云：`3778678`、`music.163.com/#/playlist?id=...`；播放走外链，VIP 歌曲自动跳过；
  - 酷狗：`kugou.com/yy/special/single/1287338.html`；免费歌曲可直接播放；
  - QQ音乐：`y.qq.com/n/ryqq/playlist/7729596131`；免费歌曲可直接播放；
  - 汽水音乐：接口需登录且音频 DRM 加密，匿名暂无法导入播放（如需支持需自建后端，如部署 qishui-api）。
- **搜歌**：输入歌名/歌手，在 网易云 / 酷狗 / QQ音乐 三个源中搜索可免费播放的歌曲，点击结果直接加入队列播放，⬇ 可单曲下载；VIP 歌曲自动跳过。
- **单曲解析**：粘贴歌曲链接或 ID（网易云/酷狗/QQ，支持短链自动跳转），解析详情与播放地址后入队播放/下载；「解析服务地址」默认 `https://api.injahow.cn/meting`（Meting 兼容公共实例，实测可用），可换自建实例；解析/下载均优先走解析服务取更高音质直链（VIP 歌曲是否可用取决于所配服务，版权请自行负责）。
- **侧边栏**：左上角 ☰ 打开菜单，集中管理「收藏歌曲 / 收藏歌单 / 音源管理」。
- **收藏**：队列与搜索结果中 ♥ 收藏歌曲（侧边栏 ❤️ 查看，点击播放、⬇ 下载、✕ 移除）；导入成功的歌单可点「★收藏歌单」，侧边栏 📑 一键重新导入。
- **音源导入**：侧边栏 🔌 音源管理粘贴 lx-music-source 格式音源 JS 地址即可导入，导入后在「搜歌」中作为新渠道使用；音源为第三方代码，可能涉及版权/付费内容，请合法使用。注意：依赖 Node 环境（vm/fs）的压缩音源无法在 App 内运行（如 pdone/lx-music-source 的 latest.js 合集），请使用纯浏览器型音源。
- **四种播放顺序**：点模式按钮循环切换 顺序播放 ➡️（播完即停）→ 列表循环 🔁 → 单曲循环 🔂 → 随机播放 🔀，选择会被记住。
- **倍速播放**：点倍速按钮在 0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x 间循环切换，选择会被记住。
- **歌曲下载**：队列每行 ⬇ 按钮单曲下载，或「全部下载」批量保存到 下载/MusicPlayer 目录（仅可解析的免费歌曲；VIP/付费/加密歌曲无法解析，自动跳过并提示，下载仅用于个人离线收听）。
- **播放队列**：点歌播放、单曲删除、一键清空；队列与模式保存在本地，重启不丢失。
- **适配**：深色主题、大触控按钮、竖屏单手操作，面向小米 Note 17 Pro 屏幕优化。

## 快速体验（不用编译，先跑起来）
把下面这个文件直接拷到手机或电脑浏览器打开即可（在电脑上双击也行）：
```
app/src/main/assets/www/index.html
```
- 浏览器模式下：点“选择音乐文件 / 文件夹”导入本地音频；
- 歌单导入走公开代理接口（效果取决于代理可用性，App 模式下更稳定；酷狗/QQ 的播放地址解析仅在 App 模式下完整可用）。

## 构建安装（真机 App，推荐）
环境要求：Android Studio（Ladybug 或更新，自带 JDK 17）。

1. 用 Android Studio 打开本项目目录 `music-player`；
2. 首次打开若提示缺少 Gradle Wrapper，按提示生成并 Sync 即可；
3. 手机开启“开发者选项 + USB 调试”，连接小米 Note 17 Pro，点 Run ▶；
4. 首次启动会请求“音乐和音频”权限，同意后自动导入本地音乐。

命令行构建（需要本机装有 Gradle 8.7+ / JDK 17）：
```
gradle wrapper
./gradlew assembleDebug
```
产物：`app/build/outputs/apk/debug/app-debug.apk`

## 权限说明
| 权限 | 用途 |
| --- | --- |
| READ_MEDIA_AUDIO（Android 13+）/ READ_EXTERNAL_STORAGE（Android 12-） | 扫描本地音乐 |
| INTERNET | 访问网易云接口 |

不上传任何数据，全部在本机处理。

## 常见问题
- **歌单导入失败/为空**：仅支持公开歌单；私密歌单或需登录的歌单无法匿名获取（QQ 私密歌单会提示 “check privacy error”）。
- **部分歌曲无法播放/下载**：VIP、付费或版权受限歌曲匿名地址不可用，播放器会自动跳到下一首，下载时自动跳过。
- **VIP 歌曲能下载吗**：不能。VIP/付费/DRM 加密歌曲需要登录态并绕过平台保护才能获取，本应用不做也不提供该能力；下载仅支持可正常播放的免费歌曲，用于个人离线收听。
- **下载的文件在哪**：Android 10+ 保存到系统「下载/MusicPlayer」目录（文件管理器可见）；Android 9- 保存在 内部存储/Download/MusicPlayer。
- **汽水音乐无法导入**：汽水音乐接口需登录态且音频为 DRM 加密，匿名方案无法实现；如需支持需自建后端服务（例如部署 [qishui-api](https://github.com/guowenye/qishui-api)）。
- **自动导入没生效**：在系统设置中允许“音乐和音频”权限后，点“扫描设备音乐”。
- **本地歌曲放不出来**：请确认文件是常见音频格式（mp3/flac/wav/m4a/aac/ogg 等）且未被系统隐藏。
